## Question
Can a small, explicit admissibility filter separate proposal preference from transition validity and return coherent operational outcomes across six constructed scenarios?

## Method
A standard-library Python toy model defines: (1) a state with representation level, risk, and capability; (2) candidate actions; (3) an explicit risk limit by representation level; (4) an admissibility predicate; and (5) a resolver that selects only admissible actions and labels the resulting mode.

The proposal policy is deterministic utility ranking. It is **not MCTS or UCT**. The risk thresholds are hand-authored for this toy and are not learned or universal.

## Scenarios and Acceptance Criteria
1. Inadmissible top preference with a valid alternative → REDIRECT.
2. More than one admissible successor → BRANCH.
3. Single admissible successor near the constraint boundary → SLOWDOWN.
4. Transition to a lower representation level → FOLD.
5. Transition to a higher representation level → UNFOLD.
6. No admissible successor → TERMINATE.

Pass criterion: each scenario returns its expected mode, and the run exits successfully only if all six assertions hold.

## Execution
Command: `python experiment.py`
Environment: Python 3, standard library only.
Result artifact: `EXP-001-RESULTS.json`.

## Limitations
The resolver's mode labels still use explicit conditional rules. Therefore this experiment does **not** derive all outcomes from a single universal mathematical law; it checks a small interface and separation-of-concerns pattern only. It does not establish dimension independence, robust safety, real MCTS behavior, or generalization to external systems.
